# LangFix 🌐

**Fix text typed in the wrong keyboard language — Hebrew ↔ English.**

LangFix is a lightweight text correction tool designed to help users fix typing mistakes caused by using the wrong keyboard language. It converts text between Hebrew and English, making everyday typing faster and more convenient.

## ✨ Features

- **Hebrew ↔ English conversion** — Correct text typed in the wrong keyboard layout.
- **Browser Extension** — Fix typing mistakes directly in your browser.
- **Windows Desktop App** — Designed to make text correction available beyond the browser.
- **Simple and Convenient** — Quickly correct text without retyping it manually.

## 📦 Project Structure

- `browser-extension/` — The browser extension.
- `desktop-app/` — The Windows desktop application.

## 🚀 Getting Started

### Browser Extension
1. Download or clone this repository.
2. Open your browser's extension management page.
3. Enable Developer Mode.
4. Select **Load unpacked** and choose the `browser-extension` folder.

### Windows Desktop App
1. Navigate to the `desktop-app` folder.
2. Follow the installation instructions provided with the application.
3. Launch the application and follow its usage instructions.

*Note: The desktop application is currently under development.*

## 🛠️ Technologies

The project uses JavaScript and browser extension technologies for the browser version. The desktop application's technologies depend on its implementation.

## 🎯 Goal

LangFix aims to make multilingual typing easier by reducing the frustration of accidentally typing in the wrong keyboard language.
